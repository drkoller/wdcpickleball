# DCPL Preview Design Palette v1

This is the INITIAL preview palette for the redesign.

These colors are intentionally provisional and are intended to guide the preview redesign.

Before any production deployment, the official vector logo (SVG or AI) should be sampled to determine the final production brand colors.

## Primary Blue

#163D73

Purpose:

- Primary brand identity
- Navigation
- Hero
- Footer
- Major headings

## Dark Blue

#12325E

Purpose:

- Hover states
- Hero gradients
- Secondary dark surfaces

## Deep Blue

#0C2345

Purpose:

- Footer
- Deep overlays
- Maximum visual depth

## DCPL Red

#BE1E4A

Purpose:

- Editorial accents
- Three stars
- Small emphasis elements

Use sparingly.

## DCPL Yellow

#F7F400

Purpose:

- Primary CTA buttons
- Important actions
- Key numbers
- Highlights

Yellow should remain bright, clean, and energetic.

Avoid muted or earthy yellow tones.

Yellow should be used sparingly so that it remains a strong visual cue rather than a dominant interface color.

## White

#FFFFFF

Purpose:

- Primary page background
- Content
- Reading areas

## Light Gray

#E8EDF3

Purpose:

- Borders
- Dividers
- Subtle structure

## Color Philosophy

Blue represents identity.

Yellow represents action.

Red provides restrained editorial emphasis.

White creates breathing room.

Gray provides structure.

Green is intentionally absent from the interface palette.

Natural greens should come from photography of courts, parks, and outdoor play rather than interface elements.

## Accessibility

All future color combinations should satisfy WCAG AA contrast requirements for normal text.

Yellow should primarily be used for buttons, badges, highlights, and graphical accents rather than body text.
